- Condition: EVENTGUARD, RANDOM_COPY 0%, seed 31.
- Firmware image hashes: Sensor `ed005d22ed2c5f44c33d9fa52fc5077dd2b68ce0f8030f991540e4ba51f6115d`; Gateway `83492c7972d8f8fb2d5b2dff20cdfc3872db919dfb433031c23f0805be4f25dd`.
- Observation: both boards completed all 54 samples. Sensor logged 112 DATA copies and 112 accepted ACKs; Gateway logged 54 deliveries, 58 duplicates, 112 ACK transmissions, no CRC or injection drops.
- Bug: new host analysis read the `SAMPLE` serial fields at indices 2/4/5 instead of 3/5/6, so it treated `GOOD` as a copy count and marked the run failed.
- Fix: parser field indices corrected in commit `13860fb`. The saved raw log was replayed offline: 54 sample records, zero sample differences, zero issues. The affected condition was rerun from RESET; it was not counted as completed on the failed attempt.
- Scope: host parser only. Core algorithm, fault calendar, trace, and firmware source did not change; firmware image hashes remained the same.

Future failed or incomplete rerun attempts are copied into `raw/attempts/` before replacement.

## Smoke attempt 4: DATA receipt accounting

- Condition: EVENTGUARD, RANDOM_COPY 20%, seed 31. This run remains **failed** because of uncontrolled missing radio frames; its raw logs are preserved.
- Bug: the legacy hardware parser incremented `physical_data_received` for an application-injected `DROP,DATA` line. The host simulator uses this field for frames received **after** injection. That mixed two observation points and exaggerated host/hardware disagreement.
- Fix: `physical_data_received` now counts valid `RX` frames after injection. `physical_data_before_injection` counts valid `RX` plus injected `DROP,DATA` frames, and `uncontrolled_physical_data_missing` counts sent DATA copies with neither log. The raw log is unchanged; parser-derived manifests are reproducibly regenerated by `tools/reparse_hardware_validation.py`.
- This correction does **not** explain the uncontrolled missing frames. No seed, threshold, loss calendar, algorithm, or firmware source was changed.

- This is **not** classified as a resolved engineering bug. The evidence does not locate the missing frame inside RF, E220 buffering, or gateway UART reception. The preregistered smoke gate remains failed; no main-matrix run was started and the seed was not changed.
